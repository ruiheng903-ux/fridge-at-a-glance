# 冰箱里有什么

一款中文家庭冰箱清单。打开 `index.html` 即可使用，无需安装依赖或注册账号。

## 用法

- 点「放入食材」，输入或快捷选择名称，填写数量、单位、冷藏或冷冻分区。相同食材可以按批次分开记录。
- 到期日可选，按包装或你自己要跟进的日期填写。清单按日期排序，今天至后天到期的食材出现在「快到期」，超过填写日期的单独列在「已过期」。
- 点「用掉」扣减部分数量，用完会移出清单，当次操作可以撤销。点「编辑」可以改分区或日期。
- 「看看示例冰箱」打开独立的演示数据。实际库存保存在当前设备和浏览器的本地存储中，清除站点数据会清空库存。

## 运行

下载仓库并双击 `index.html`，或在项目根目录运行 `python -m http.server 8080 --bind 127.0.0.1` 后打开 http://127.0.0.1:8080 。网页可以直接部署到静态网站服务。
